# Password Input

Accepts a password with a built-in visibility toggle.
Use `Field` for an accessible label, supporting text, and validation feedback.

## Usage

<div style={{ overflowX: "auto" }}>

```tsx
import { Field } from "@workspace/ui-react/components/field";
import { PasswordInput } from "@workspace/ui-react/components/password-input";

<Field className="grid gap-2">
  <Field.Label>Password</Field.Label>
  <PasswordInput
    name="password"
    autoComplete="current-password"
    placeholder="Enter your password"
  />
</Field>
```

</div>

<Canvas of={PasswordInputStories.Default} />

## Props

Inherits `Input` props except `type` and `rightSlot`, which the component manages.
Use `autoComplete="current-password"` for sign-in and `autoComplete="new-password"` when creating a password.
`className` styles the input itself; put layout classes on a parent to size the whole field.

## Visibility

`defaultVisible` sets visibility only on mount; `visible` manages it externally and requires `onVisibilityChange` to update that prop when the toggle is used.
The password value and its visibility are independent: revealing or hiding it does not change its value.

<Canvas of={PasswordInputStories.Visibility} />

**Current accessibility limitation:** the built-in visibility toggle has no accessible name and is excluded from the Tab order.
Labeling the input does not label the toggle.

## Left slot

Use `leftSlot` for non-interactive context, such as a lock icon; padding adjusts to its width.
Keep a visible label and mark decorative icons `aria-hidden="true"`.

<Canvas of={PasswordInputStories.LeftSlot} />

## States

Set `disabled` directly on `PasswordInput` to disable both the input and its toggle, prevent focus, and exclude the value from form submission; `Field disabled` alone does not disable the toggle.
`readOnly` prevents editing but keeps the input focusable and included in form submission, with the visibility toggle still active.
Use `Field invalid` with `Field.Error` to expose invalid state and explain the error.
