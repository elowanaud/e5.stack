# Button

Triggers an action, such as saving a form, opening a menu, or confirming a deletion.
Built on the Base UI button, the component uses theme colors in both light and dark modes.
It renders an HTML `button` element by default.

## Usage

```tsx
import { Button } from "@workspace/ui-react/components/button";

<Button onClick={handleSave}>
  Save
</Button>
```

## Variants

Choose a variant based on the action’s role in the interface.

<table style={{ width: "100%", display: "table" }}>
  <thead><tr><th>variant</th><th>Recommended use</th></tr></thead>
  <tbody>
    <tr><td><code>default</code></td><td>Secondary action with a neutral background and a border. The default variant.</td></tr>
    <tr><td><code>primary</code></td><td>Main action within a section or form.</td></tr>
    <tr><td><code>ghost</code></td><td>Subtle action with no background at rest, for example in a toolbar.</td></tr>
    <tr><td><code>destructive</code></td><td>Destructive action, such as deletion. Request confirmation when the action is irreversible.</td></tr>
  </tbody>
</table>
