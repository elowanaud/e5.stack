# Separator

Visually and semantically separates groups of content using the Base UI Separator primitive.
`Separator` is the public export of `SeparatorRoot` and by default renders a `div` with `role="separator"`.
Lines use `bg-neutral-6`; horizontal text uses `text-neutral-11 text-sm`.

## Usage

```tsx
import { Separator } from "@workspace/ui-react/components/separator";

<Separator />
<Separator>Or continue with</Separator>
```

## Props

Accepts Base UI Separator props, native `div` attributes, event handlers, ARIA attributes,
`style`, and `ref`. `SeparatorProps` is the public discriminated union type.
`SeparatorHeadless` exposes the unstyled Base UI primitive when needed.

## Horizontal content

Use `children` for text or other visible inline content. With `align="left"`, content precedes
a single line; with `align="right"`, content follows a single line. The default, `align="center"`,
places equal-length lines on both sides.

Falsy children (`0`, `""`, `false`, `null`, or `undefined`) render a plain line without a label.
To display zero as text, pass the string `"0"`. Children are otherwise rendered directly,
without a content wrapper.

```tsx
<Separator align="left">Or continue with</Separator>
<Separator>Or continue with</Separator>
<Separator align="right">Or continue with</Separator>
<Separator>{"0"}</Separator>
```

## Vertical separators

Give the separator or its parent an explicit height. The default vertical separator fills its
parent's height and is one pixel wide. The TypeScript API rejects both `children` and `align`
when `orientation="vertical"`. JavaScript callers' vertical children and alignment are ignored;
vertical separators never render text.

```tsx
<div className="flex h-16 items-center gap-4">
  <span>Overview</span>
  <Separator orientation="vertical" />
  <span>Details</span>
</div>
```

## Customization

`className` styles the root, including with a Base UI state callback. Labeled horizontal
separators contain one or two empty line spans, depending on alignment, alongside the supplied
content. For string content, target the lines with `[&>span]:bg-primary-6` to change their color.
This selector also affects any direct child spans supplied in `children`.

<Canvas of={SeparatorStories.Customization} />

Use `render` to customize the root. A custom element must forward the supplied props,
children, and ref and preserve the separator role and orientation.
